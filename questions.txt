I trained and evaluated three different models on the Titanic dataset: a Logistic Regression, a Random Forest Classifier, and an XGBoost Classifier.
All models were trained on the same preprocessed features and evaluated on the same validation set for a consistent comparison.
The Logistic Regression model achieved an accuracy of 82.68%, performing surprisingly well for a linear model.
The Random Forest model followed with an accuracy of around 77–78%, while the XGBoost model reached approximately 80–81%, indicating a small but consistent improvement over Random Forest.
For Class 0 (non-survivors), Logistic Regression achieved high precision and recall (around 0.85 and 0.87), slightly outperforming the ensemble models in this class.
However, for Class 1 (survivors), both Random Forest and XGBoost captured patterns that the linear model missed — XGBoost, in particular, achieved a higher recall (~0.72) compared to Random Forest (~0.68).
In summary:
•	Logistic Regression: best generalization and simplicity; top overall accuracy.
•	Random Forest: robust and interpretable, but slightly less accurate.
•	XGBoost: best balanced performance, higher recall for survivors.
Overall, while Logistic Regression surprisingly leads in total accuracy, XGBoost provides a stronger balance across all metrics and would likely perform better with more tuning.
